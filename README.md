# MAD Inclass 05 - Profile Details App

SE303.3 Mobile Application Development - Mini Project 01, built with React Native (Expo).

A "My Profile" screen with an app bar, profile picture, Name, Email and Points.
The `+` button adds one point on every tap (`useState`).

## Run

```
npm install
npx expo start
```

Scan the QR code with Expo Go, or press `a` for an Android emulator / `i` for the iOS simulator.
